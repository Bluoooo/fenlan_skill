# 粉蓝偶记 · AI 写作风格 Skill

## 这是什么

这是微信公众号「粉蓝偶记」的写作风格 Skill。基于 62 篇、73,700 字真实文章提炼，包含完整的风格 DNA：

- 句式节奏（平均句长、长短句比例、连接词偏好）
- 词汇指纹（高频词、叠词、口语词、禁用词）
- 修辞习惯（歌词引用、比喻、通感、蒙太奇手法）
- 情感底色（"温暖的忧郁"、粉蓝情绪坐标系）
- 语态切换（深情↔搞笑、口语↔文艺、自我对话）
- 时间记号（精确日期/天数计数/时钟时间/季节节气）
- 感官体系（通感、嗅觉、听觉、触觉、温度即情绪）
- 16 条写作禁忌

## 快速开始

### 方式一：ChatGPT (Custom GPT)

1. 打开 ChatGPT → 左上角"探索 GPT" → "创建"
2. 在"Instructions"框中粘贴 `SKILL.md` 的**全部内容**
3. 在 Knowledge 区域上传 `articles.md`
4. 命名 GPT 为"粉蓝偶记"
5. 使用时在对话中 @粉蓝偶记 即可

### 方式二：Claude (Projects)

1. 打开 Claude → 创建新 Project
2. 在 Project Knowledge 中粘贴 `SKILL.md` 内容
3. 上传 `articles.md` 到 Project Knowledge
4. 在 Project 内对话即可自动加载风格

### 方式三：其他 AI 平台

将 `SKILL.md` 全文粘贴到 System Prompt / Custom Instructions / 角色设定区域。
如果平台支持文件上传，额外上传 `articles.md` 作为参考语料。

### 方式四：直接在对话中使用

在任意 AI 对话开头粘贴：
> 请以微信公众号「粉蓝偶记」的风格写作。以下是风格指南和参考文章：
> [粘贴 SKILL.md 全文]
> [粘贴 articles.md 全文，或上传该文件]
> 现在请写一篇关于 XXX 的文章。

## 注意事项

- `articles.md` 包含个人写作内容，请勿公开分享
- SKILL.md 约 5000 字，部分 AI 平台可能有 System Prompt 长度限制，可以删减末尾的"样本参照"段落
- 如果想切换风格时期（早期偏文艺 / 近期偏成熟），可以在提示中额外说明"用粉蓝偶记 2023 年的风格写"
